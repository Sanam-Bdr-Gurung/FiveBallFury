# 🎯 FiveBallFury

**FiveBallFury** is a colorful, physics-based arcade game built using SpriteKit and Swift. Drop vibrant balls, score through slots, and try to clear all obstacles — but you only have **five chances**! It’s a fast-paced test of strategy, timing, and precision.

---

## 🧩 Gameplay

- Drop balls from the top of the screen into spinning slots.
- Good slots increase your score, bad ones take it away.
- Obstacle boxes add challenge and can be knocked away by your shots.
- You start with **5 balls** — use them wisely!
- Landing on a **green slot** earns you an extra ball.
- Tap **Reset** to clear the board and start fresh.

## 🛠 What I Learned with SpriteKit & Swift

Working on **FiveBallFury** helped me explore several core concepts in SpriteKit development:

- ⚙️ **Physics Simulation** — Using `SKPhysicsBody` to simulate gravity, collision, and restitution.
- ✋ **Touch Handling** — Managing player interactions using `touchesBegan`.
- 🧱 **Scene Composition** — Building scenes with `SKSpriteNode`, `SKLabelNode`, and layering visuals.
- 🎨 **Randomization** — Dynamically generating colors, sizes, and ball types.
- 📊 **Game State Management** — Tracking score, ball limits, and editing/resetting game states.
- 💥 **Particle Effects** — Adding visual flair through `SKEmitterNode`.
